【*】程序简介

-工程名称：CAN收发器模块双机通信
-实验平台: 野火小智 STM32 F103C8T6 核心板

按下KEY1使CAN发送数据，当CAN接收到扩展ID为0x1314的数据包时会把数据打印出来

/*********************************************************************************************/
【*】实验操作与注意事项：

实验操作
1.核心板掉电情况下，将模块引出脚按照xxx引脚连接说明.xlsx，接到板子对应脚上
2.确保引脚对应接上的情况下，核心板上电，将例程编译成功后，下载到核心板里
3.核心板的USB转串口通过数据线连接电脑，同时确保电脑安装了串口驱动并能识别到核心板的串口
4.电脑端使用串口调试助手，选择电脑与核心板相连的COM口，设置为115200-N-8-1并打开
5.复位核心板，即可接收核心板串口发送给电脑的数据
6.将两个CAN模块通过导线连接，H对H、L对L、GND对GND
7.将其中一个CAN模块的拨码拨至ON(打开状态)，或者两个模块的拨码都打开，由实际情况决定
8.按下KEY1使CAN发送数据，发送时LED3灯点亮，发送完熄灭
9.当CAN接收到扩展ID为0x1314的数据包时会把数据打印出来，打印时LED2点亮，打印完熄灭

注意事项
模块上的拨码控制是否需要插入120欧姆的电阻，两模块通信时，必须有一个拨码处于打开状态(拨码ON时开启接入)，或者两个都打开，由实际情况决定

大部分情况不用接EN脚，RXD与TXD的电平由主控提供，当RXD与TXD需要输入输出指定电压时，接入EN脚，这时RXD与TXD的电压受EN脚接入电压影响

若要修改报文、报文ID、数据段长度等，需要同步修改stm32f10x_it.c里报文的判断条件

本例程中的CAN波特率为1MBps，为stm32的CAN最高速率

若要进行回环测试可不外接CAN模块，将bsp_can.c的can结构体配置的Mode修改为回环模式即可

/*********************************************************************************************/
【*】引脚分配

TTL转CAN模块 ：
    EN  <---> 悬空
    5V  <---> 5V
    GND <---> GND
    TXD <---> PB9
    RXD <---> PB8

LED ：
    LED1 <---> PA1
    LED2 <---> PA2
    LED3 <---> PA3
    
KEY ：
	KEY1 <---> PA0
	KEY2 <---> PC13
    
串口（TTL-USB TO UART）：
CH340的收发引脚与STM32的发收引脚相连
	CH340  RXD  <--->  USART1  TX  (PA9)
	CH340  TXD  <--->  USART1  RX  (PA10)
